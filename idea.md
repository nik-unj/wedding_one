Build a **premium, modern, cinematic digital wedding invitation website/platform** inspired by high-end Indian wedding invitation experiences.

The goal is to create an invitation that feels like a **luxury interactive wedding experience**, not a normal static wedding card or generic landing page.

Use the following reference websites for understanding the type of experience and feature depth:

- https://marwari.memorialink.in/
- https://ivory-royal.memorialink.in/

Do NOT copy their branding, exact layouts, text, assets, or visual design. Create a completely original design inspired by the same level of elegance and interactivity.

---

# 1. Overall Design Direction

The website should feel:

- Luxury
- Cinematic
- Elegant
- Emotional
- Premium
- Indian wedding inspired
- Sophisticated rather than overly flashy
- Mobile-first
- Highly immersive

Think of the experience as a combination of:

**Luxury wedding invitation + cinematic website + interactive story**

Use elegant typography with a combination of:

- Premium serif display font
- Elegant script/accent font
- Clean modern sans-serif for supporting text

Use subtle animations, gold/ivory/cream/black/deep maroon/emerald/royal tones depending on the selected theme.

Avoid the typical cheap-looking wedding website aesthetic.

Animations should feel smooth, expensive and intentional.

- weddingDate

- hero

- events[]

Each event should support:

- id
- name
- date
- startTime
- endTime
- description
- venue
- address
- mapsUrl
- dressCode
- image
- calendarEnabled

This will allow the same website engine to create hundreds of different wedding invitations later.
